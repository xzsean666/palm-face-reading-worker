# Goal: 天机 AI预测大师 (Tianji AI Divination Worker)

## 1. 项目背景与目标

「天机 AI预测大师」是一款融合中国传统古籍数理易理（《麻衣神相》《许负相法》《渊海子平》《奇门遁甲》《三才五格姓名学》等）与前沿多模态大语言模型、深度 RAG（检索增强生成）技术的边缘 Serverless 预测应用。

整个系统运行在 **Cloudflare Workers** 边缘运行时上，底层全面接入 **`AI-Session-NodeJS`** SDK，前端高度还原 `docs/design/stitch_ui` 所定义的 **Mystic Cyber-Occultism（神秘赛博玄学）** 深色暗金设计系统（18 个高保真页面、10 大功能表单）。

---

## 2. 核心能力范围

### 2.1 十大核心测算门类与专业知识库

系统需涵盖以下 10 个算命预测门类，每个门类具备独立的 System Prompt、专业知识库切片（RAG）和表单输入输出结构：

1. **AI 看相（手相 / 面相 / 面手合参）**：
   - 依赖多模态视觉大模型（GPT-4o / Llama-3.2-Vision / Gemini 等）。
   - 知识库基础继承并扩充 `/ssd0/git/AI-Session-NodeJS/examples/palm-face-reading`。
   - 包含图像质检（采光、角度、磨皮滤镜）、几何微观度量（三停比例、印堂两指宽、卧蚕 vs 眼袋、生命线/智慧线/感情线、断掌/川字掌）、六大面手合参格局（天圆地方、潜龙在渊、逢凶化吉等）。
2. **我们合不合（双人八字婚恋与合作配对）**：
   - 双方出生年月日时、性别、关系类型（情侣/夫妻/合伙人/朋友）。
   - 纳音五行相生相克、生肖冲合害刑、十神配对、灵魂契合度指数。
3. **测手机车牌（数字能量学 × 八字契合）**：
   - 手机号 11 位、车牌号 8 位与八星磁场（天医、延年、生气、伏位 vs 绝命、祸害、五鬼、六煞）。
   - 号码数理吉凶与车主/机主生辰八字五行喜忌契合。
4. **测姓名店名（三才五格全息总评）**：
   - 天格、人格、地格、总格、外格数理吉凶计算。
   - 康熙笔画、五行音律与主人八字旺衰互补。
5. **择日吉日（天时地利 · 钦天择吉）**：
   - 事项类别（结婚、开业、搬家、动土、签约、出行）。
   - 黄道吉日、廿八宿、建除十二神、主事人八字冲煞方位避忌。
6. **未来运程（流年大运轨迹推演）**：
   - 跨度（今年/三年/五年），流年干支生克、关键转折点年份与四季运势曲线。
7. **八字推测（正统子平命盘详批）**：
   - 公历/农历干支排盘、四柱八字、藏干十神、五行旺衰强弱、喜用神定论。
8. **成败预测（兵家奇门遁甲决疑）**：
   - 所问事项（创业、投资、考试、求职、竞标、诉讼）与计划时空。
   - 奇门九星、八门、八神时空盘排布与胜算概率评测。
9. **个人起名（八字喜用康熙字典深度定制）**：
   - 姓氏、性别、八字喜忌、单双字、意象期望（睿智/康健/富贵/文雅/英武）与避讳字。
   - 给出精选天命吉名方案矩阵（声调、字形、寓意、诗词出处）。
10. **公司取名（法人命理与行业契合商号战略）**：
    - 法人八字、行业赛道、主体类型、期望风格。
    - 给出纳财旺企商号方案、五行相生及招财锦囊。

### 2.2 边缘后端核心能力 (Cloudflare Worker)

1. **`AI-Session-NodeJS` 边缘自适应运行**：
   - 开启 `nodejs_compat` 兼容环境。
   - 实现符合 `IStorage` 接口的 `D1SessionStorage`，在 **Cloudflare D1** 中持久化多轮会话记录与状态。
2. **无盘虚拟知识库（Virtual RAG Bundle）**：
   - 将全套相学、命理、奇门、姓名学等 Markdown 知识库打包为内存虚拟结构（`knowledge-bundle.json`），免宿主机磁盘依赖。
   - 运行时根据测算类型与用户输入特征动态调用 SDK 内存 RAG 检索最相关章节。
3. **真实流式推演（SSE Streaming）**：
   - 支持 Server-Sent Events（`text/event-stream`），实现打字机式逐步推演、实时状态变更（正在排布命盘... 正在推演五行...）。
4. **订单与分级报告体系**：
   - **免费预览报告（P07）**：精简结论、核心评分指数与付费遮罩墙。
   - **付费完整报告（P09）**：命盘全息可视化、分章节手风琴深度解读、PDF 生成与下载。
   - 免费测算次数（新用户 2 次）与 USDT 支付（TRC20 / ERC20）解锁机制。
5. **会员体系与分润返佣引擎**：
   - 月度、季度、年度会员档位与权益检查。
   - 专属推荐码生成、直推 15%、间推 5% 佣金计算与 D1 记录、提现申请管理。

### 2.3 前端 UI 规范与成熟框架选型

1. **视觉风格：Mystic Cyber-Occultism（神秘赛博玄学）**
   - 严格遵循 `docs/design/stitch_ui/ai_ui.md` 规定的调色板与组件：
     - 主色：`--tj-primary: #D4AF37`（鎏金）、`--tj-primary-light: #F5D97E`
     - 背景：`--tj-bg: #0B0E1A`（深夜靛蓝黑）、`--tj-bg-card: #141828`、`--tj-bg-card-hover: #1B2138`

     - 文字：`--tj-text-primary: #F3EFE3`（米白）、`--tj-text-secondary: #9CA0B5`
   - 全局动词表规范严格执行（查看、解锁、支付、开通、开始等）。
2. **页面覆盖度（18 个高保真页面）**：
   - P01 启动页 (`/splash`)
   - P02 登录页 (`/login`)
   - P03 测算首页 (`/home`，无底栏，10大功能宫格)
   - P04 功能二级选择页 (`/feature/palm-face`)
   - P05 信息录入页 (`/feature/:type/input`)
   - P06 分析中页 (`/feature/:type/analyzing`，星盘太极罗盘转动动效)
   - P07 报告预览页 (`/feature/:type/preview`，模糊付费墙遮罩)
   - P08 支付页 (`/pay`)
   - P09 完整报告页 (`/feature/:type/report`)
   - P10 会员中心 (`/vip`)
   - P11 推广中心 (`/promote`)
   - P12 收益明细与提现 (`/promote/earnings`)
   - P13 个人中心 (`/me`)
   - P14 测算记录 (`/me/records`)
   - P15 订单详情 (`/me/orders/:id`)
   - P16 分享落地页 (`/invite/:code`)
   - P17 说明与免责声明 (`/about`)
   - P18 统计页 (`/stats`)
3. **全局导航模式**：
   - 顶部 56px 一级主导航（☰抽屉 / ←返回、标题、铃铛、金色＋动作按钮）。
   - 左侧 72% 抽屉主菜单。
   - 底部弹出的「＋」全局动作面板（Action Sheet）。
   - 44px 二级横向滑动副菜单导航。
4. **前端框架选型推荐**：
   - 选用 **Vue 3 + Vite + Tailwind CSS**（配合 Cloudflare Workers 的 Static Assets 资产托管）：
     - 为什么最简单成熟：`stitch_ui` 原型全部使用 Tailwind CSS 和原生 HTML 结构，Vue 3 的 SFC（单文件组件）语法能几乎 1:1 无缝粘合这些 HTML/Tailwind 代码；
     - 状态管理使用 Pinia，轻量且适合管理用户 Session、免费次数、钱包地址与测算草稿；
     - 打包体积极小（生产 bundle 几十 KB），Cloudflare Worker 可以毫秒级极速分发静态资源。

## 3. 非目标与系统边界

1. **不自建重型区块链节点**：应用支持 Web3 钱包连接（EIP-1193 / TronLink / 模拟连接）与 USDT 转账哈希上链记录，但不运行底层共识节点。
2. **不搞迷信恐吓**：严格落实免责声明，测算内容定位于“传统文化娱乐推演与积极心理学认知”，避免绝对论断或有害建议。
3. **敏感图片隐私保护**：用户上传的面相、手相照片仅在推演请求生命周期中编码使用，或在 D1 中保存短生命周期记录，不做长期外流。

## 4. 完成定义 (Definition of Done)

1. 全套 Cloudflare Worker + 前端静态托管配置完成，`wrangler dev` 本地能够一键拉起完整全栈应用。
2. D1 数据库初始化与迁移脚本正常运行，包含会话表、订单表、用户表、佣金表。
3. `AI-Session-NodeJS` SDK 成功在 Cloudflare Worker 中适配运行，D1SessionStorage 读写正常。
4. 10 大算命门类 Prompt 与虚拟知识库切片打包完毕，支持普通问答与 SSE 流式推演。
5. 前端完整还原 Stitch UI 的 18 个页面、10 大功能表单及暗金赛博玄学设计系统。
6. 端到端流程通畅：进入首页 -> 选择功能 -> 录入表单 -> 星盘推演 -> 免费预览 -> 模拟支付/免费次数抵扣 -> 查看完整分章报告。
