## 使用方式

1. 投喂时按顺序拼接：「全局设计系统」+「全局导航组件」+ 任一「页面生成指令卡」= 一条完整生成指令；
2. 每张页面卡自包含：布局、精确文案、样式、全部界面状态，无需额外上下文；
3. 文案必须逐字使用卡内文案，不得改写；变量用 `{{变量名}}` 占位；
4. 生成目标为移动端 H5（375×812 逻辑分辨率），深色主题；
5. 人称统一「您」；按钮文案只允许使用动词表内动词。

## 1.2 字体规范

- 字体栈：中文 `PingFang SC, Microsoft YaHei, Noto Sans SC`；数字 `DIN Alternate, Bahnschrift`
- 导航标题 17px/600；模块标题 20px/600；正文 14px/400；辅助说明 12px/400；价格 22px/700（金色）；报告正文 15px/400、行高 1.8
- 品牌名「天机 AI预测大师」用书法体（生成时可近似为衬线体加字距）

## 1.3 间距与圆角

- 页面边距 16px；卡片内边距 16px；区块间距 12px；卡片间距 12px
- 主按钮圆角 24px（胶囊）；卡片圆角 16px；输入框圆角 12px；弹窗圆角 20px
