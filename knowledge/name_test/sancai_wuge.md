# 三才五格剖象法推算体系

## 1. 五格数理计算公式
三才五格法以《康熙字典》正体字笔画数为基准：
- **天格（祖先运）**：
  - 单姓：姓氏笔画 + 1；
  - 复姓：两姓氏笔画相加。
- **人格（主运，核心自我）**：
  - 单姓单名：姓氏笔画 + 名字笔画；
  - 单姓双名：姓氏笔画 + 名第一字笔画；
  - 复姓：姓氏第二字笔画 + 名第一字笔画。
- **地格（前运，中年以前及配偶子女）**：
  - 单名：名字笔画 + 1；
  - 双名：名字两字笔画相加。
- **总格（后运，中年至晚年终身归宿）**：
  - 姓名全部文字笔画总和。
- **外格（副运，社交人际与外界环境）**：
  - 总格数理 − 人格数理 + 1（或特定单名公式）。

## 2. 三才吉凶配置
三才即天格、人格、地格对应五行（1-2木，3-4火，5-6土，7-8金，9-10水）：
- **相生吉配置**（如木火土、土金水、水木火）：基础稳固，境遇安泰，得贵人扶持，一生顺遂；
- **相克凶配置**（如金木相战、水火相克）：多有挫折，易生内耗，虽得一时成功难免晚景飘摇。
