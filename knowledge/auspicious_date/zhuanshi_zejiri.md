# 择日吉日学：各大专事择吉实操秘旨

## 择吉总法纲领与三合天德

钦天监《协纪辨方书》择日铁律：“顺天行事，合人合地。年利不如月德，月德不如日吉，日吉不如时良。”

### 择日核心四要素：
1. **主事人本命生肖与八字**：绝不可犯本命地支“天克地冲”或“岁破日破”。
2. **建除十二神择用**：除、定、执、危、成、开为吉；建、满、平、破、收、闭审慎。
3. **黄道吉日值神**：青龙、明堂、金匮、天德、玉堂、司命为六黄道大吉。
4. **避开恶煞凶日**：杨公十三忌、四绝四离日、红沙日、岁破日、十恶大败日。

## 四大核心专事择吉秘传

### 1. 开业开市 / 签约商贸择吉
- **首选用神**：喜天德、月德、天愿、岁德、开日、成日、满日。
- **神煞宜忌**：
  - 大吉神：青龙值日、明堂值日、禄马贵人汇聚、食神生财日。
  - 严忌：四废日、破日、闭日、大耗日及受死日。
- **时辰挑选**：宜辰时（早晨7-9点，龙腾虎跃）或巳时（上午9-11点，日照中天），取生意蒸蒸日上之祥瑞。

### 2. 嫁娶合婚 / 订婚安床择吉
- **首选用神**：女命大利月、三奇日、六合日、天德月德合、成日、定日。
- **神煞宜忌**：
  - 大吉：天喜、红鸾、不将日（阴阳不将，嫁娶大吉）。
  - 严忌：月破、受死、往亡、四穷日、白虎当值无制。
- **避讳重点**：日子地支不可与新人双方父母本命生肖相冲克。

### 3. 动土修造 / 奠基开工择吉
- **首选用神**：除日、定日、执日、成日，地气生旺之日。
- **方位煞位严防**：
  - 务必查验所修宅邸或工地的太岁方、三煞方（申子辰年三煞在南巳午未；寅午戌年三煞在北亥子丑）。三煞所临方位切忌首先动土。
  - 严忌：土皇四季交接各前十八日大忌动土，忌土瘟、土符、土鬼凶煞。

### 4. 移徙乔迁 / 入宅安香择吉
- **首选用神**：开日、成日、黄道吉日，天德月德照临。
- **入宅仪式与时辰**：宜选午前（卯时、辰时、巳时，阳气充盈升腾），不可在傍晚或子夜入宅；主事人手捧火炉或吉礼进门，主满堂红火。
