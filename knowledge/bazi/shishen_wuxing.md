# 十神生克格局与五行旺衰强弱

## 1. 十神六亲象意
十神以日干为中心，由五行生克分化而来：
- **比肩 / 劫财**：同我者。比肩代表同辈、朋友、自尊与意志力；劫财代表竞争、魄力、冒险与财帛分夺。
- **食神 / 伤官**：我生者。食神为福寿之星，代表才华、温和、口福与创造力；伤官代表叛逆、求变、机智、商道锐气与突破规矩。
- **正财 / 偏财**：我克者。正财代表勤勉稳健所得、妻子、稳定现金流；偏财代表意外之财、投资机变、大格局经营与慷慨仗义。
- **正官 / 七杀**：克我者。正官代表律法、贵气、公职名誉与正统统御力；七杀（偏官）代表魄力、威严、攻坚克难、军警威权与压力磨砺。
- **正印 / 偏印**：生我者。正印代表慈善、文凭、学术信誉与贵人长辈庇护；偏印（枭神）代表超常洞察、玄学技术、孤傲与独创思维。

## 2. 五行旺相休囚死
- 当令者旺，令生者相，生令者休，克令者囚，令克者死。
- 身旺者宜抑，取官杀克身、食伤泄秀或财星耗身；
- 身弱者宜扶，取正偏印生身或比劫帮身。
