# 天命吉名方案矩阵：音形义理四维评分体系

## 1. 四维全息评估准则
每一个起名方案均需通过四大维度的严密推敲（总分 100 分）：
1. **五行喜用契合（30 分）**：字义部首与八字喜用神精准匹配；
2. **三才五格数理（25 分）**：天、地、人、总、外五格无大凶数理，人格地格大吉；
3. **字形字态优美（20 分）**：间架结构稳重端庄，无重偏头歪脚，易读易写易签名；
4. **文化意蕴出处（25 分）**：诗文原典引证深厚，寄托长辈对智慧、健康、富贵、品德之美好期望。

## 2. 输出方案梯度
- 为当事人提供 3-5 组精选天命方案；
- 每组方案明确标注：姓名、拼音与声调、康熙笔画、五行属性、三才数理评分、典籍出处原句与宗师寄语。
