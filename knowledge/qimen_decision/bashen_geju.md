# 奇门八神吉凶格局与时空神煞

## 1. 八神灵应指引
八神代表神秘冥冥机缘与不可抗力影响：
- **值符**：万神之领袖，所到之处百恶消散，第一大吉神；
- **腾蛇**：主虚惊怪异、心思摇摆、噩梦缠绕、协议反复；
- **太阴**：主阴庇贵人、策划保密、女子相助、暗中筹谋；
- **六合**：主婚姻恋爱、商务谈判、合伙签约、调解中介；
- **白虎**：主强力冲撞、血光竞争、突发阻碍、严厉铁腕；
- **玄武**：主暗昧不明、投机小人、虚假信息、文书隐匿；
- **九地**：主坚守沉静、长期守成、置业沉淀、宜守不宜攻；
- **九天**：主名扬四海、高瞻远瞩、航空远行、大举进攻。

## 2. 经典奇门战局
- **天遁**：丙奇 + 生门 + 临生宫，经商求财天下第一吉局；
- **地遁**：乙奇 + 开门 + 己土，宜于隐匿安居、修造建置；
- **人遁**：丁奇 + 休门 + 太阴，求贤选官、和睦相伴之良局。
